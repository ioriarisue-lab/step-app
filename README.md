# ステップ動作解析（オフラインPWA） v1.0.1

歩行角度解析アプリ（gait-app v1.8.0）をもとにした、ステップ動作の解析アプリです。iPhone・iPad・Android・Windows/Macで、撮影→端末内に保存→解析。解析はすべて端末上で行い、動画や結果を外部へ送信しません。

## 公開（GitHub Pages）
1. GitHubで新しいリポジトリ step-app を作り、このフォルダの中身をすべて（フォルダに分けず）アップロード。いちばん大きいファイルは ort-wasm-simd-threaded.jsep.wasm（約21MB）で、どれも25MB以下です
2. Settings → Pages → Branch を main / (root) にして保存
3. https://ioriarisue-lab.github.io/step-app/ をSafariなどで開き、「ホーム画面に追加」

## 初回設定（端末ごと）
- 「設定」タブで pose_landmarker_heavy.task を取り込む（gait-appとは保存場所が別なので、このアプリでも必要）
- または gait-app と同じく、モデルの .part1/.part2（RTMPoseは rtm_det.onnx.partN / rtm_pose.onnx.partN）をリポジトリに置くと自動で読み込まれます
- 「モデル(.task)を取り込む」で分割ファイルを取り込むときは、.part1と.part2を同時に選ぶ（つないで保存）。間違えて取り込んだら「削除」
- 以後は機内モードでも使えます

## 撮影
- 対象者の真横から全身と足先が入るように撮影。カメラはステップの方向に対して直角に向ける（斜めだと誤差が出る）
- 介助者は対象者の後ろ（背中側）に立つ。体の向きの側（前側）にいる人を対象者として追跡
- ステップ前に、膝を伸ばして1秒ほど静止して立つ場面を入れる（cm換算に使う）

## 解析設定
- 体の向き（画面上で右向き／左向き）、ステップの方向（前方／後方）
- 基準足（支持側：右／左）と踏み出す足（既定は基準足の反対側。「基準足」も選べる）
- 対象者ID と 下肢長（転子果長：大転子〜外果, cm）。IDごとに端末内に保存し、次回は自動で入る（「設定」タブで確認・削除）
- 対象者のタップ指定：「この場面の人を表示して選ぶ」で、その場面で検出された人を番号つきの骨格で表示 → 対象者の骨格をタップ。複数の場面で指定でき、指定した場面から次の指定の手前まで、その人を追跡します（重なって入れ替わったときの選び直し用）

## 解析の方法
- 対象者の追跡：フレームをまたいで同じ人を追跡。近くに候補が複数あるとき（介助者と重なったとき）は前側の人を優先。見えないフレームは別の人に乗り換えず空欄
- 1回のステップ：踏み出す足の離地〜踵の接地
  - 離地：踏み出す足（踵と足関節の平均）の水平位置が速く動き始めた時点
  - 接地：踏み出した後、踵の上下座標が床の高さに戻った最初の時点
- ステップ距離：踵・足関節それぞれの、離地直前から接地時までの水平移動量×換算係数。下肢長に対する割合（%）も出力
- 換算係数（cm/px）＝転子果長 ÷ 動画内の下肢長（股関節の点〜足関節の点）。換算区間の左右の平均を使用（左右それぞれの係数と、それで換算した距離も出力）
- 換算区間の自動検出：静止＋左右の膝の屈曲20度未満＋前後関係（前方ステップは基準足が前、後方ステップは踏み出す足が前。膝も同じ前後関係）が0.3秒以上続く区間。最初のステップより前を優先。見つからないときは条件をゆるめる
- 結果画面で、換算区間（秒）と下肢長を直して再計算できます（姿勢推定はやり直さない）
- 角度：股関節（体幹線に対する大腿、屈曲＋・伸展−）、膝（屈曲＋）、足関節（下腿と踵→つま先、背屈＋・底屈−）、体幹の傾き（前傾＋）
- 反対方向の動き（元の位置に戻す動きなど）は別の表に出力

## 出力
- 結果画面：ステップ1回ごとの一覧（距離・時間・角度）、平均・SD、左右差（右−左）、換算係数と区間、グラフ、スティックピクチャー動画
- *_steps.csv（ステップ一覧。換算係数・区間も列に記録）
- *_frames.csv（フレーム別の座標・角度・足の前後位置cm）
- *.xlsx（ステップ一覧・平均・左右差・反対方向の動き・換算係数・フレーム別・説明）
- *_graph.png、*_stick_figure.mp4

## 注意
- カメラが進行方向に対して直角でないと、距離・角度に誤差が出ます
- 姿勢推定の「股関節」の点は大転子より少し下・内側にあり、転子果長とは一致しません。換算にはこの分の誤差が含まれます
- 真横からの単眼動画による2D推定であり、臨床測定・診断には使用できません
